Mot de passe oublié

Le mot de passe administrateur se réinitialise sur le serveur (accès shell), sans avoir besoin d'être connecté. Lance l'une de ces commandes :

Déploiement (LXC / VM)

sudo bash /opt/site-base/deploy/reset_admin.sh

En local (dev)

python -m panel.reset_admin

La commande demande le nouveau mot de passe (saisie masquée), puis tu peux te reconnecter en local.
